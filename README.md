## 구성

| 폴더 | 형성평가 | 내용 |
|------|----------|------|
| [quiz01](quiz01/Main.java) | 형성평가 1 | `System.out.print` 로 문자열 출력 |
| [quiz02](quiz02/Main.java) | 형성평가 2 | `println` 과 `print` 의 줄바꿈 차이 |
